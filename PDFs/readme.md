## How to Learn Actively
1. Read one PDF section.
2. Open the matching folder README.
3. Run at least one SQL script.
4. Write your own variation and compare results.

## Debugging prompts while studying
- Which clause changes row count most?
- Where can duplicates appear?
- What index would make this query faster?
- Is the query safe for user input?
